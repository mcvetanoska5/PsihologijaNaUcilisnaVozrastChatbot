This repository contains a simple web-based chatbot developed as part of personal projects to explore AI-driven conversational interfaces. The main goal of this project is to implement a friendly chatbot that provides psychological guidance, advice, and educational support in Macedonian using OpenAI’s language models.

* Technologies and Tools

Programming Languages: HTML, CSS, JavaScript

Libraries / APIs: OpenAI API (GPT-4o-mini)

Environment: Any modern web browser

Optional Tools: Node.js / .env for secure storage of API keys
 
* Project Description

A user-friendly chatbot interface where users can type questions related to stress, feelings, jealousy, or general psychological well-being.

The chatbot responds in Macedonian using AI-generated answers from OpenAI.

Frontend-only implementation with responsive design and interactive UI.

Secure handling of OpenAI API keys recommended via environment variables (.env) instead of hardcoding them in the HTML.

Demonstrates practical understanding of integrating AI APIs into web applications.

* How it Works

The user opens the ChatBot.html file in a browser.

The chatbot greets the user with an introductory message.

Users type questions in the input field and click "Send" or press Enter.

The input is sent to the OpenAI API, which generates a response.

The response is displayed in the chat interface dynamically.
